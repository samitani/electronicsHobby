# Christmas Illumination (ESP32 WS2812B) 🎄✨

ESP32 と WS2812B フルカラーLEDテープ（60個）を使用した、スマートフォンから操作可能なクリスマスイルミネーションシステムです。

ハードウェア構成および回路配線は `LEDShoot` と完全に同一です。

---

## 1. ハードウェア構成

| 部品 | 仕様・型番 | 接続先 | 備考 |
|---|---|---|---|
| **マイコン** | ESP32-DevKitC-32D | - | Wi-Fi通信 & LEDアニメーション制御 |
| **LEDテープ** | WS2812B（5V, 60 LED） | DIN ──▶ レベルシフタ 1Y | 縦型またはツリー・壁面配置 |
| **レベルシフタ** | SN74AHCT125N | 1A ──▶ ESP32 GPIO 25 | 3.3V ──▶ 5V 昇圧 |
| **保護抵抗** | 330Ω | 1Y と LED DIN 間 | 信号ライン保護 |
| **電解コンデンサ**| 1000μF 10V以上 | 5V 電源ライン間 | 電源安定化 |
| **電源** | 5V 4A以上 | 回路全体へ供給 | 共通グランド（Common GND） |

* **LED配置設定**: `LED_DIN_IS_TOP false`（LEDShootと同様、DIN側が下端）

## 2. 収録イルミネーションパターン

1. **🍬 Candy Cane（キャンディケイン）**:
   - 赤と白、アクセントグリーンのストライプが流れるようにスクロールするクリスマス定番演出。
2. **❄️ Snowfall（降雪と星空）**:
   - 静寂な夜空（濃紺）を背景に、複数の雪の結晶がゆっくり舞い落ち、星がきらめく幻想的なパターン。
3. **🎄 Christmas Tree（モミの木とオーナメント）**:
   - 深いグリーンのツリーをベースに、ゴールド・ルビー・サファイア・ホワイトのオーナメントライトがふんわり呼吸点灯（ブリージング）。
4. **🌌 Silent Night Aurora（オーロラ）**:
   - エメラルドグリーン、シアン、ブルー、パープルが優しく波打つ、聖夜のオーロラグラデーション。
5. **🔥 Cozy Fireplace（暖炉の炎）**:
   - 暖炉の火種から赤・オレンジ・黄色の炎がパチパチと揺らめき立ち上る、温かみのある演出。
6. **🌈 Holiday Rainbow（レインボー）**:
   - 華やかな全色グラデーションが滑らかに循環するフェスティバル演出。

## 3. スマートフォンWebUI機能

ESP32のローカルIPアドレス（例: `http://192.168.1.xxx`）にブラウザでアクセスして操作します。

* **Power ON / OFF**: イルミネーションの点灯 / 完全消灯切り替え。
* **パターン選択**: 6種類のパターンをワンタップで切り替え。
* **Auto Cycle（自動巡回）**: 20秒ごとに自動で次のパターンへ切り替わるショーケースモード。
* **Brightness スライダー**: 部屋の明るさに合わせて輝度を 10%〜100% で無段階調整。
* **Speed スライダー**: アニメーション速度を 0.3x〜3.0x で調整。
